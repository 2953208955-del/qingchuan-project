# 演示样例图（public/samples）

`npm run seed` 需要以下 3 张真实巡检照片，文件名必须完全一致：

| 文件名 | 内容要求 | 用途 |
| --- | --- | --- |
| `sample-1.jpg` | 河岸或水面，能看清至少 2 个塑料瓶和 1 个塑料袋 | 演示任务第 1 张；也是 `npm run eval:agent` 的输入图 |
| `sample-2.jpg` | 岸线或浅水处，包含废弃渔网/渔具，最好另有玻璃瓶或包装袋 | 演示任务第 2 张（含低置信待复核目标） |
| `sample-3.jpg` | 水面漂浮泡沫碎块，最好另有塑料瓶 | 演示任务第 3 张（含低置信待复核目标） |

三张图只用于本地/演示环境。演示种子脚本会读取真实字节、计算 SHA-256，并在
`DATA_DIR/uploads/` 下复制出稳定的 `demo-sample-*.jpg` 文件，不会覆盖用户上传的同名文件。

**在图片补齐之前，`npm run seed` 会以非零退出码失败，并提示缺少哪些文件；不会写入任何演示数据。**

## 隐私要求

- 画面中不得出现可识别的**人脸**、**车牌**、门牌号、身份证件等个人信息。
- 无法避免时，先做模糊/打码或裁剪，再放入本目录；不要上传原图再依赖模型处理。
- 避免拍摄私人院落、军事设施等敏感区域；涉及私人财产时先取得同意。
- **上传前请自行移除 EXIF/GPS 等元数据**：应用会原样保存上传的图片字节，不会自动剥离 EXIF。
- 样例图提交到仓库后，其元数据也会随 Git 历史保留；仅在应用侧删除不算清除。
- 样例图会随仓库公开，提交前请再次确认没有隐私信息。

## 说明

- 仓库不预置样例图，避免用编造或来源不明的图片冒充真实巡检数据。
- 如果图片放在其他位置，请同步修改本说明和 `scripts/seed-demo.ts` 中的路径，但文件名仍建议保持一致。

## 重新写入演示数据

`scripts/seed-demo.ts` **先检查三张样例图，再检查 `demo-run-001` 是否存在**，因此：

- 样例图缺失时一定以非零退出码失败，且不写入任何数据；
- 成功 seed 后再删掉样例图，重跑会因样例缺失而失败，而**不会**打印“跳过”；
- 样例图仍在且 `demo-run-001` 已存在时，重跑只打印“演示数据已存在，跳过”。

如需用新照片重新生成演示数据，请先删除该任务及其关联行（或换一个干净的 `DATA_DIR`）：

```sql
DELETE FROM reports WHERE run_id = 'demo-run-001';
DELETE FROM detections WHERE run_id = 'demo-run-001';
DELETE FROM images WHERE run_id = 'demo-run-001';
DELETE FROM runs WHERE id = 'demo-run-001';
```

然后在三张样例图齐全的情况下重新运行 `npm run seed`。只删除 `uploads/` 下的演示图片而不删除
数据库记录，会让页面引用不存在的图片。
